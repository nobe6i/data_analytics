# data_analytics
Home work assignments and in class lectures from my BAN 612 Data Analytics class at CSU-East Bay

BAN 612: Data Analytics

Welcome to the repository for BAN 612: Data Analytics. This course offers a hands-on, practical approach to the end-to-end modern data analytics workflow, with an emphasis on extracting, transforming, exploring, and visualizing messy, real-world data to drive strategic business decisions.

Course Overview

Real-world business data is rarely perfectly structured or clean. This course focuses on practical problem-solving using open-source programmatic tools to handle heterogeneous, complex datasets. Key domain applications include:
• Business and Market Analytics: Integrating internal and external data to evaluate industry opportunities and competitive landscapes.
• Customer Analytics: Profiling behavioral patterns and mapping distinct segments to measure satisfaction and retention factors.
• Web and Digital Analytics: Programmatically extracting information from live online infrastructure.
• Operations and Decision Support: Analyzing internal operational matrices to isolate performance deltas and system anomalies.

Core Topics Covered

• Modern Analytics Workflow: Moving programmatically from raw, imperfect data formats to production-ready dataset pipelines.
• Data Ingestion & Multi-Format Parsing: Programmatic workflows to ingest, read, and cross-examine data across various storage types, including CSV, Excel, and JSON.
• Data Quality, Cleaning, and Integration: Methodologies for identifying missing values, structural inconsistencies, duplicated rows, and handling invalid fields.
• Web Scraping & API Data Extraction: Connecting to external environments to pull unstructured text and parsed layouts using native requests and application programming interfaces (APIs).
• Exploratory Data Analysis (EDA) & Reshaping: Reshaping, merging, and grouping matrices to identify meaningful behavioral trends, statistical boundaries, and correlations.
• Data Visualization: Designing comprehensive graphs and interactive layouts to communicate data insights to managerial audiences.
• AI-Assisted Analytics: Integrating generative AI tools into the workflow to assist with code synthesis, data cleaning, and interpretation while maintaining human auditing for accuracy and validity.

Tech Stack & Tools

The projects and assignments in this course are implemented using the Python ecosystem within Jupyter Notebooks or Google Colab:
• Data Manipulation: Pandas, NumPy
• Data Visualization: Matplotlib, Seaborn, Plotly
• Web Ingestion: Requests, Web-Scraping Tools (e.g., BeautifulSoup)
